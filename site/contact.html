What not to send publicly

Do not post passwords, API keys, private story drafts, personal addresses, phone numbers, account information, safety reports, or other sensitive details in a GitHub issue. This is not an emergency service or a confidential reporting channel.

Before the community launches

Storyloom needs a dedicated, monitored support and moderation email address. The operator must add that address here before writers or readers can create accounts. Until then, GitHub issues are only for public project feedback.

Need a real moderation contact? Create an email inbox you can monitor every day, such as support@your-domain, then tell me the address and I will add it to the site and policies.
